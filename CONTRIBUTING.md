# Contribuir

Trabaja en una rama, mantén los cambios pequeños y añade pruebas para las reglas operativas. Antes de proponer cambios ejecuta `pnpm run typecheck`, `pnpm run lint`, `pnpm run test` y `pnpm run build`. No añadas datos reales, secretos, copias de seguridad ni credenciales. Los cambios de esquema requieren una migración nueva y nunca deben reescribir migraciones ya desplegadas.
