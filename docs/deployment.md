# Despliegue

- Frontend PWA: preparado para GitHub Pages con `pnpm build:pages`.
- Backend: Sites/Cloudflare Worker con D1 mediante `.openai/hosting.json`.
- Producción objetivo: dominio HTTPS, base protegida, autenticación real y RLS equivalente en servidor.
- El repositorio contiene solo código y fixtures sintéticos. Datos reales y backups no se publican en Git.
- Verificaciones previas: instalación reproducible, lint, typecheck, tests, build, migraciones y smoke test público.
